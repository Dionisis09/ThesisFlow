# Οδηγός παρουσίασης ThesisFlow

## Η βασική ιδέα

Το ThesisFlow είναι μία εφαρμογή Node.js που εξυπηρετεί τρεις ρόλους: Φοιτητή, Διδάσκοντα και Γραμματεία. Ο browser ζητά δεδομένα από JSON APIs και ο server εφαρμόζει τους κανόνες πριν ενημερώσει τη SQLite βάση.

```text
Browser (HTML/CSS/JavaScript)
              |
              | fetch / JSON
              v
        Express routes
              |
              v
        SQLite database
```

## Τα αρχεία που αξίζει να δείξεις

1. `server.js`: εκκίνηση Express, sessions, static αρχεία και headers ασφαλείας.
2. `node_app/auth.js`: σύνδεση χρήστη, έλεγχος ρόλου και CSRF.
3. `node_app/routes.js`: APIs, μεταβάσεις κατάστασης και εισαγωγές δεδομένων.
4. `node_app/db.js`: queries, συναλλαγές, μετατροπή δεδομένων και indexes.
5. `web/static/js`: διαφορετικό UI για κάθε ρόλο με κοινό API helper.
6. `tests_node/app.test.js`: ολοκληρωμένος έλεγχος της εφαρμογής μέσω HTTP.

## Εκκίνηση

```powershell
npm install
npm start
```

Η εφαρμογή ανοίγει στο `http://127.0.0.1:5000`.

## Προτεινόμενο demo 8 λεπτών

### 1. Σύνδεση και ρόλοι - 1 λεπτό

- Σύνδεσε έναν χρήστη από κάθε ρόλο.
- Δείξε ότι κάθε χρήστης οδηγείται στο δικό του dashboard.
- Εξήγησε ότι το `requireRole(...)` προστατεύει τα APIs και το `requirePageRole(...)` τις σελίδες.

### 2. Διδάσκων - 3 λεπτά

Λογαριασμός: `prof001@uni.local` / `password`.

- Δημιούργησε ή επεξεργάσου θέμα.
- Δείξε την αρχική ανάθεση θέματος σε φοιτητή.
- Άνοιξε τις διπλωματικές και τα φίλτρα κατάστασης/ρόλου.
- Δείξε προσκλήσεις επιτροπής, σημειώσεις, βαθμολογία και στατιστικά.

### 3. Φοιτητής - 2 λεπτά

Λογαριασμός: `student001@uni.local` / `password`.

- Δείξε τα στοιχεία της διπλωματικής και της επιτροπής.
- Δείξε upload PDF και προσθήκη βοηθητικού συνδέσμου.
- Δείξε τα στοιχεία παρουσίασης και την επεξεργασία προφίλ.

### 4. Γραμματεία και δημόσιο feed - 2 λεπτά

Λογαριασμός: `sec@uni.local` / `password`.

- Φίλτραρε τις διπλωματικές ανά κατάσταση.
- Δείξε καταχώριση πρακτικού, ακύρωση και περάτωση.
- Δείξε import JSON πρώτα με προεπισκόπηση.
- Άνοιξε `/api/public/presentations` και `/api/public/presentations?format=xml`.

## Κύκλος ζωής

```text
UNDER_ASSIGNMENT
       |
       | δύο αποδοχές επιτροπής
       v
     ACTIVE
       |
       | στοιχεία παρουσίασης
       v
   UNDER_EXAM
       |
       | τρεις βαθμοί + σύνδεσμος αποθετηρίου
       v
   COMPLETED

ACTIVE / UNDER_EXAM -> CANCELED με απόφαση ΓΣ
```

Οι μεταβάσεις ελέγχονται πάντα ξανά στον server. Το UI δεν μπορεί να παρακάμψει τους κανόνες.

## Συχνές ερωτήσεις

### Γιατί χρησιμοποιείται JavaScript παντού;

Η ίδια γλώσσα καλύπτει server και browser, άρα η υλοποίηση παραμένει μικρή και εύκολη στην παρουσίαση.

### Γιατί SQLite;

Είναι open-source σχεσιακή βάση, λειτουργεί χωρίς ξεχωριστό database server και υποστηρίζει foreign keys, συναλλαγές και indexes.

### Πώς προστατεύεται το σύστημα;

Με bcrypt passwords, server-side sessions, `HttpOnly` cookie, CSRF token, role guards, validation εισόδων και έλεγχο πραγματικού PDF header στα uploads.

### Πώς αποδεικνύεται ότι λειτουργεί;

```powershell
npm run check
npm test
npm run db:verify
```

Τα integration tests ανοίγουν πραγματικό HTTP server σε προσωρινή θύρα και χρησιμοποιούν απομονωμένο αντίγραφο της βάσης.
